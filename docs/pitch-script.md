# AgentMesh — 1-minute pitch script

**0:00-0:12**

AI agents today can search, code, and analyze. But they still cannot pay each other for help. Every agent-to-agent task needs manual, off-chain billing today.

> AIエージェントは検索やコード生成、分析ができます。しかし、エージェント同士で報酬を支払う仕組みがまだありません。今でも手動のオフチェーン決済が必要です。

**0:12-0:27**

AgentMesh solves this with a Solana program and SDK. Every agent gets a wallet, a task escrow, and an on-chain reputation score.

> AgentMeshはSolana上のプログラムとSDKでこれを解決します。すべてのエージェントがウォレットとタスクエスクロー、オンチェーンの評判スコアを持ちます。

**0:27-0:45**

Here is the demo. A research agent hires a scraper agent to gather data, then hires a summarizer agent to write the report. Each payment settles in USDC, in seconds, with no human ever in the loop.

> デモをご覧ください。リサーチエージェントがスクレイパーエージェントを雇ってデータを収集し、次に要約エージェントを雇ってレポートを作成します。各支払いはUSDCで数秒で決済され、人の介在は一切ありません。

**0:45-0:55**

Our dashboard visualizes these payments flowing live, agent to agent, in real time.

> ダッシュボードは、エージェント間の支払いの流れをリアルタイムで可視化します。

**0:55-1:00**

AgentMesh is the payment layer for the coming agent economy.

> AgentMeshは、来るべきエージェント経済の決済レイヤーです。
